# notifytodone

Notifytodone is a project designed to increase my productivity, and help with managing tasks. It integrates with Todoist, which is an online
todo list service that through an account can be synced across any device. The idea for notifytodone is that every so often (currently every
half an hour) I will get a notification containing one of the items on my todo list, selected randomly. This means that if I am not overly
busy, then I will be reminded of a task that I need to complete and can complete it. As the data is continually pulled from the Todoist API
when a task is marked as complete through todoist, it will also drop out of the random selection for the notifications, which ensures that
I do not get a notification for a task that I have already completed.
